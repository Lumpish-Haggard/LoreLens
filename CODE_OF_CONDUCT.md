# Code of Conduct

## The short version

Be decent to each other. We are here because we like reading novels and like
making a small tool better. Nothing here is worth being unpleasant over.

## What we expect

- Assume good faith. Most disagreements are two people with different context.
- Critique code, not people. "This regex backtracks on long chapters" is useful.
  "This is garbage" is not.
- Respect that contributors read different novels, on different devices, in
  different languages. A bug you cannot reproduce is still a real bug.
- Keep spoilers out of issues, PR descriptions, screenshots and test fixtures
  unless the title says `[spoilers]`. This project exists partly to protect
  people from spoilers; the repo should hold the same line.

## What is not acceptable

- Harassment, insults, or personal attacks of any kind.
- Discriminatory language or imagery, including in test data and sample text.
- Publishing someone's private information.
- Deliberately posting spoilers to annoy people.
- Sustained disruption of discussions.

## Scope

This applies in the repository — issues, pull requests, discussions, commit
messages, code and comments — and anywhere someone is representing the project.

## Reporting

Open a GitHub issue if it is something the whole project should see, or contact
the maintainers privately through GitHub if it is not. Reports are handled as
confidentially as the platform allows.

Maintainers may edit, hide, or delete contributions that violate this document,
and may block accounts for repeated or severe violations. Maintainers who do not
follow this document in good faith should be reported the same way as anyone
else.
